# YarnHinge

Microservices orchestrator leveraging distributed, auto-scaling clusters for real-time data processing with optimized performance through YarnHinge's smart broker.

With YarnHinge, you get a lightweight tool that stays out of your way.

**What you get**

- Microservices orchestrator leveraging distributed, auto-scaling
- clusters for real-time data processing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/YarnHinge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
